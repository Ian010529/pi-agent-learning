Pi Architecture — Quick Reference

这是压缩参考，不替代 lesson。事实来源以当前 Pi source 为准。

Core layers

packages/ai
  model/provider boundary
        ↓
packages/agent
  generic stateful agent
  agent loop + tool execution + events + queues
        ↓
packages/coding-agent
  coding harness
  system prompt + coding tools + skills + sessions + compaction + extensions + MCP

Minimal execution

  ↓

  ↓
runAgentLoop(...)
  ↓

  ↓
streamAssistantResponse(...)
  ↓
AssistantMessage
  ├─ text only
  │    ↓
  │  no natural continuation
  │    ↓
  │  follow-up check → end
  │
  └─ toolCall(s)
       ↓
     validate / execute
       ↓
     ToolResultMessage(s)
       ↓
     append to context
       ↓
     next provider request

Three distinctions to preserve

Do not collapseReason
LLM vs AgentLLM produces an assistant message; Agent schedules requests, tools, context and lifecycle.
Agent core vs Coding harnesspackages/agent is generic; coding behavior is assembled above it.
Session history vs model contextPersistent history can remain while later model requests use a transformed/compacted context.
